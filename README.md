# Terraform AWS Data Sources Project
This project demonstrates how to use Terraform Data Sources to fetch existing AWS infrastructure resources and use them while creating a new EC2 instance.

## 📌 What I Learned
- Terraform Data Sources
- Fetching existing VPC
- Fetching existing Subnet
- Fetching existing Security Group
- Fetching AWS Region
- Fetching Availability Zones
- Launching EC2 using existing infrastructure
